# Thrift Shop Web Tools

A simple, embeddable dashboard designed for thrift shop volunteer coordination. This tool can be added directly to a **Google Site** using the "Embed HTML" feature. Once installed, it provides volunteers and staff with immediate access to:

- **Time Sheet Interface**: An embedded view of your current time tracking system.
- **Volunteer Sign-Up Portal**: A clearly labeled link that opens your dedicated volunteer registration site in a **new browser tab**, ensuring users can keep multiple time sheet sessions open without interference.
- **True New Tab Button**: A convenient button that bypasses the dashboard and opens a standard browser new tab—useful for general browsing or multitasking.

This setup is ideal for shared computers in donation drop-off areas, sorting rooms, or volunteer check-in stations, helping streamline daily operations while maintaining flexibility.
