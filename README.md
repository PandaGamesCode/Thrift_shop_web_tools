# Thrift Shop Web Tools 

A lightweight, embeddable dashboard designed to streamline volunteer coordination in thrift shops. Easily integrated into **Google Sites** using the "Embed HTML" feature, this tool gives staff and volunteers instant access to essential resources—all from a single, clean interface.

## ✨ Features

- **Time Sheet Interface**: Embedded view of your existing time-tracking system for quick clock-ins/outs.  
- **Volunteer Sign-Up Portal**: A clearly labeled link that opens your registration site in a **new browser tab**, allowing users to keep time sheet sessions active without disruption.  
- **True New Tab Button**: Launches a standard browser new tab—perfect for multitasking or general browsing on shared workstations.

Ideal for donation drop-off zones, sorting rooms, or volunteer check-in stations, this dashboard enhances daily operations while maintaining flexibility and ease of use.

## 🛠️ Setup Guide: Hosting on Google Sites

Follow these steps to deploy the dashboard as your own website using Google Sites:

1. **Copy the HTML** from `Web_tools_V2.html` in this repository.
2. Go to [sites.google.com](https://sites.google.com) and create a **blank site**.
3. On the right sidebar, click **Pages** → hover over the **+** icon → select **Full-page embed**. Name it anything (e.g., “Dashboard”).
4. Click the **three-dot menu** next to your new page and select **Set as homepage**, then delete the default page.
5. Click **Insert** → **Embed** → **Embed code**.
6. Paste the copied HTML and click **Insert**.
7. Click **Publish**, give your site a name (the name doesn’t affect functionality), and confirm.

✅ You now have a live, personal website hosted under your Google account!

## 🌐 Set as Your Default New Tab

Once published, you can replace your browser’s default new tab with this dashboard using the **Custom New Tab** extension.

### For Chrome
1. Install the [Custom New Tab extension](https://chromewebstore.google.com/detail/custom-new-tab/lfjnnkckddkopjfgmbcpdiolnmfobflj?hl=en) from the Chrome Web Store.
2. Copy the **published URL** of your Google Site (ensure it’s published!).
3. Click the **Custom New Tab** icon in your browser toolbar (top-right).
4. Paste your site’s URL into the **New Tab URL** field and click **Save**.
5. Open a new tab—you should now see your dashboard instead of Chrome’s default page.

### For Microsoft Edge
1. Install the [Custom New Tab extension](https://microsoftedge.microsoft.com/addons/detail/custom-new-tab/mhbdgafkbjagobahdhphkahiejfmchpb) from the Edge Add-ons store.
2. Copy the **published URL** of your Google Site.
3. Click the **Custom New Tab** icon in the toolbar.
4. Paste your URL into the configuration box and click **Save**.
5. New tabs will now load your dashboard automatically.

> 💡 **Tip**: This setup is especially useful on shared computers in thrift shop backrooms—keeping volunteers focused and workflows efficient.
